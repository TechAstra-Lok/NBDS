{% if lang == 'ne' %}रक्तदान जीवनदान: तपाईंको एक थोपा, कसैको जिन्दगी!{% else %}Blood Donation Guidelines: Your Drop, Their Life!{% endif %}

{% if lang == 'ne' %} रक्तदान गर्नु अघि, गरिरहँदा र गरिसकेपछि ध्यान दिनुपर्ने आवश्यक स्वास्थ्य मापदण्ड तथा निर्देशिकाहरू। {% else %} Essential health standards and guidelines to follow before, during, and after blood donation. {% endif %}

{% if lang == 'ne' %}को-कसले रक्तदान गर्न सक्छन्? (योग्यता){% else %}Who Can Donate? (Eligibility){% endif %}

  • {% if lang == 'ne' %} उमेर: १८ वर्ष पूरा भई ६० वर्ष नहालेको हुनुपर्नेछ। {% else %} Age: Must be between 18 and 60 years old. {% endif %}
  • {% if lang == 'ne' %} तौल: न्यूनतम ४५ किलोग्राम (४५ केजी) वा सोभन्दा माथि भएको हुनुपर्नेछ। {% else %} Weight: Must be at least 45 kg or above. {% endif %}
  • {% if lang == 'ne' %} रक्तचाप र हेमोग्लोबिन: रक्तचाप सामान्य (सिस्टोलिक १००-१४० र डायस्टोलिक ६०-९०) भएको र हेमोग्लोबिन १२.५ ग्राम/डिएल भन्दा माथि हुनुपर्नेछ। {% else %} Blood Pressure & Hemoglobin: Normal BP (systolic 100-140, diastolic 60-90) and hemoglobin above 12.5 g/dL required. {% endif %}
  • {% if lang == 'ne' %} समयको अन्तराल: पछिल्लो पटक रक्तदान गरेको कम्तीमा ३ महिना (९० दिन) पूरा भएको हुनुपर्नेछ। {% else %} Donation Interval: At least 3 months (90 days) must have passed since your last donation. {% endif %}

{% if lang == 'ne' %}कसले रक्तदान गर्नु हुँदैन?{% else %}Who Should NOT Donate?{% endif %}

  • {% if lang == 'ne' %} एन्टिबायोटिक्स सेवन: एन्टिबायोटिक्स वा कडा औषधि सेवन गरिरहेका वा औषधि छोडेको १ हप्ता पूरा नभएकाहरू। {% else %} Antibiotic Use: Those taking antibiotics or strong medication, or who have not completed 1 week after stopping medication. {% endif %}
  • {% if lang == 'ne' %} गम्भीर संक्रामक रोग: एचआईभी (HIV), हेपाटाइटिस 'B' वा 'C', जण्डिस, वा मलेरिया लागेका व्यक्तिहरू। {% else %} Serious Infectious Diseases: Persons with HIV, Hepatitis B or C, Jaundice, or Malaria. {% endif %}
  • {% if lang == 'ne' %} गर्भवती वा स्तनपान: गर्भवती महिला, भर्खरै सुत्केरी भएका वा शिशुलाई स्तनपान गराइरहेका आमाहरू। {% else %} Pregnant or Breastfeeding: Pregnant women, recently delivered mothers, or those currently breastfeeding. {% endif %}
  • {% if lang == 'ne' %} ट्याटू वा पियर्सिङ: पछिल्लो ६ महिना भित्र शरीरमा ट्याटू खोपेका वा कान/नाक छेडाएका व्यक्तिहरू। {% else %} Recent Tattoo or Piercing: Those who have had a tattoo or ear/nose piercing within the past 6 months. {% endif %}

{% if lang == 'ne' %}रक्तदान गर्दाका ३ महत्त्वपूर्ण चरणहरू{% else %}3 Important Stages of Blood Donation{% endif %}

{% if lang == 'ne' %}१. रक्तदान गर्नु अघि{% else %}1. Before Donation{% endif %}

{% if lang == 'ne' %} कम्तीमा ३-४ गिलास सफा पानी पिउनुहोस्।
कम्तीमा ४ घण्टा अगाडि पोसिलो खाना खानुहोस् (खाली पेट नबस्नुहोस्)।
अघिल्लो रात कम्तीमा ७-८ घण्टा सुतेको हुनुपर्छ। {% else %} Drink at least 3-4 glasses of clean water.
Eat a nutritious meal at least 4 hours before (do not donate on an empty stomach).
Sleep at least 7-8 hours the previous night. {% endif %}

{% if lang == 'ne' %}२. रक्तदान गरिरहँदा{% else %}2. During Donation{% endif %}

{% if lang == 'ne' %} आफूलाई शान्त राख्नुहोस्, लामो र गहिरो सास लिनुहोस्।
रक्तदान गर्ने हातको मुट्ठी बिस्तारै खोल्ने र बन्द गर्ने गरिरहनुहोस्।
असहज महसुस भएमा तुरुन्त स्वास्थ्यकर्मीलाई भन्नुहोस्। {% else %} Stay calm and take slow, deep breaths.
Gently open and close your fist on the donation arm.
Immediately inform a health worker if you feel uncomfortable. {% endif %}

{% if lang == 'ne' %}३. रक्तदान गरिसकेपछि{% else %}3. After Donation{% endif %}

{% if lang == 'ne' %} रक्तदान बेडमा कम्तीमा १०-१५ मिनेट आराम गर्नुहोस्।
उपलब्ध गराइने जुस, बिस्कुट र प्रशस्त तरल पदार्थको सेवन गर्नुहोस्।
अर्को ४-५ घण्टासम्म गह्रौँ सामान उठाउने वा कडा व्यायाम नगर्नुहोस्। {% else %} Rest on the donation bed for at least 10-15 minutes.
Consume juice, biscuits, and plenty of fluids provided.
Avoid heavy lifting or strenuous exercise for the next 4-5 hours. {% endif %}
